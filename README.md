# סקר התושבים השנתי · נופי פרת

סקר תושבים במקום Google Forms: מובייל פירסט, RTL, אנונימי (שם רשות, המייל נשמר רק מוצפן), נושא אחרי נושא כשכל נושא נשמר בנפרד, המשך מכל מכשיר עם אותו מייל, הגרלה למסיימים, דשבורד לצוות עם פילוח והשוואה בין קבוצות, ודוח ציבורי מצרפי.

**התשתית:** אתר סטטי (GitHub Pages) + Google Apps Script + Google Sheets כמסד נתונים. בלי עלות ובלי שרת לתחזק. הצוות עורך שאלות ורואה תוצאות ישירות בגיליון.

## הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | הסקר עצמו (מה שהתושבים רואים) |
| `admin.html` | דף הניהול: נושאים, שאלות, טקסטים והגדרות, בסיסמה |
| `dashboard.html` | דשבורד צוות, בסיסמה |
| `report.html` | דוח ציבורי לתושבים (מצרפי בלבד, נפתח רק כשמחליטים) |
| `survey-data.js` | השאלון ההתחלתי (ותצוגה מיידית עד שהשרת עונה) |
| `appscript.gs` | השרת (Apps Script) |
| `config.js` | כתובת השרת והגיליון |
| `styles.css`, `utils.js`, `icons.js` | עיצוב, עזרים ואייקונים |
| `tests/` | בדיקות לשאלון ולשרת |

## פריסה
השרת נפרס עם [clasp](https://github.com/google/clasp) מחשבון הגוגל שמחזיק את הגיליון. הסדר:
1. יצירת גיליון + סקריפט, דחיפת `appscript.gs` ופרסום כ-Web app (Execute as: Me, Access: Anyone).
2. כתובת ה-Web app נכנסת ל-`config.js`.
3. הרצה אחת של הפונקציה `setup()` מהעורך: אישור הרשאות, יצירת הטאבים, סיסמת צוות אקראית (מופיעה בלוג ובטאב "הגדרות") וטריגר חימום.
4. דף הניהול (`admin.html`) → כניסה בסיסמה → "שמירה". בשרת ריק נטען השאלון ההתחלתי מ-`survey-data.js`.

**כל שינוי ב-`appscript.gs` מחייב פרסום גרסה חדשה על אותה כתובת**, אחרת הקוד החדש לא באוויר.

## ניהול שוטף, בלי קוד: דף הניהול

הכול נערך ב-**admin.html** (בסיסמת הצוות), ונכנס לאתר ברגע השמירה:

| מה רוצים | איפה בדף הניהול |
|---|---|
| נוסח, אפשרויות, סוג, חובה, "לא יודע/ת", תנאי הצגה | "נושאים ושאלות" → הנושא → השאלה |
| להוסיף, להסתיר, למחוק או להזיז שאלה או נושא | "נושאים ושאלות" |
| נושא בלי "לא רלוונטי אליי" | בנושא עצמו, מתג |
| פתיח, שו"ת, הגרלה, שמות התחומים | "טקסטים" |
| לסגור את הסקר, לפרסם את הדוח הציבורי, להחליף סיסמה | "הגדרות" (נשמר מיד) |

הגיליון הוא מסד הנתונים ולא עורכים בו: **תוצאות** (שורה לכל עונה), **תשובות גולמי** (גיבוי מלא), **הגרלה** (שם וטלפון בלבד), **מיילים** (מוצפנים). הטאבים מוגנים באזהרה.

## פרטיות ואנונימיות

- לכל עונה נוצר קוד אנונימי אקראי. שדה השם הוא רשות, ואין איסוף של טלפון (חוץ מההגרלה) או IP.
- **מייל (חובה):** רק כדי שכל אחד ימלא פעם אחת וימשיך מכל מכשיר. לא שולחים אליו כלום. בטאב "מיילים" נשמר רק HMAC של הכתובת, עם מפתח סודי שיושב בהגדרות הסקריפט ולא בגיליון, כך שמי שרואה את הגיליון לא יכול לדעת מי ענה. ממכשיר אחר חוזרת רק ההתקדמות (אילו נושאים נשמרו), לא התשובות.
- **"קצת עליך":** הפרטים הדמוגרפיים חובה (בטווחים, לא ערכים מדויקים), השם רשות.
- **הגרלה:** שם וטלפון בלבד, בטאב נפרד, בלי קוד העונה ובלי שעת הרשמה, והטאב ממוין לפי שם. כך אי אפשר לקשר הרשמה לתשובות. האימות שהעונה השלים הכול קורה בשרת ברגע ההרשמה ולא נשמר.
- **"התחלה מחדש"** מבטלת את התשובות הקודמות של העונה (הן נשארות בגיבוי הגולמי, אבל לא נספרות).
- **הדוח הציבורי** מציג מצרפים בלבד: בלי טקסט חופשי, בלי שמות, ושאלות עם פחות מ-5 תשובות מוסתרות.
- טלפונים, שמות וסיסמאות נשלחים לשרת בגוף הבקשה ולא בכתובת, כך שהם לא נשמרים בלוגים.

## פיתוח מקומי

- פותחים את `index.html` ישירות בדפדפן. כשהשרת לא מוגדר הסקר עובד במצב תצוגה מקדימה (שאלות מ-`survey-data.js`, שמירה במכשיר בלבד, באנר צהוב למעלה).
- `node tests/validate-survey.js`: בדיקת השאלון (מזהים, תנאים, סוגים).
- `node tests/backend.test.js`: מריץ את `appscript.gs` האמיתי מול גיליון מדומה ובודק את כל הזרימות.
- `node tests/e2e-server.js`: האתר המלא מול השרת המדומה, ב-http://localhost:5178.
